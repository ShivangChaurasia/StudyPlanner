📘 StudySync – Smart Study Planner
---
StudySync is a responsive web-based Smart Study Planner designed to help students organize subjects, manage tasks, plan schedules, and track academic progress efficiently.
The application is built using HTML, Tailwind CSS, and Vanilla JavaScript, with LocalStorage used for data persistence.
Live Link : shivangchaurasia.github.io/StudyPlanner/
---
🚀 Features
---
### 📚 Subject Management
- Add, edit, and delete subjects
- Assign priority levels (High / Medium / Low)
- Persistent storage using browser LocalStorage
- Clean card-based UI with priority indicators

### 📅 Schedule Planner
- Plan daily and weekly study schedules
- Associate subjects with time slots
- Prevents data loss on refresh


### 📝 Task Manager
- Add academic tasks (assignments, exams, deadlines)
- Track total tasks across subjects
- Stored and synced via LocalStorage

### 📊 Dashboard
- Overview of total subjects and tasks
- Highlights high-priority subjects
- Displays today’s focus subject
- Dynamic UI updates based on stored data

### 📈 Progress Tracker
- Visual overview of study progress
- Helps students analyze workload and priorities

### ⚙️ Settings
- Centralized navigation
- Designed for future extensions (theme, reset, export)

💾 Data Persistence
---

- All user data (subjects, tasks, schedules) is stored using browser LocalStorage, ensuring:
  - Data remains after page refresh
  - No backend or database required
  - Fast and lightweight performance
